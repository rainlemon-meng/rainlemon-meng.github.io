ARP 欺骗：

ARP 欺骗是局域网内实现中间人 MITM 攻击最经典的手段。

ARP：地址解析协议
作用：把IP 地址 → MAC 物理地址。
ARP 协议设计的缺陷：ARP 应答报文不需要收到请求也可以主动发送。
主机收到 ARP 回复，就直接更新自己 ARP 缓存，不会严格验证真假。攻击者就利用这个漏洞。

ARP 欺骗攻击流程（MITM 模式）

环境：

A：受害者电脑
R：路由器网关
C：攻击者主机

1.攻击者 C 持续发送伪造 ARP 应答包
A 的 ARP 缓存被篡改：网关 IP 对应的 MAC 变成攻击者机器。
于是受害者 A 所有上网流量，全部发给攻击者 C，而不是真实路由器。
发给受害者 A：网关 IP → 攻击者 C 的 MAC
2.攻击者同时发给网关 R 发送伪造 ARP 应答
网关回给 A 的流量，也先发给攻击者 C。
发给网关 R：受害者 A 的 IP → 攻击者 C 的 MAC
3.攻击者开启流量转发
攻击者机器收到双向流量，可以：
单纯窃听抓包
修改数据包内容
丢弃数据包制造断网
再把流量转发给真实网关 / 受害者
结果：A 对外所有网络流量全部经过攻击者 C，完成局域网中间人 MITM。
如果攻击者只欺骗受害者，不欺骗网关：受害者能上网，但是所有外网流量先过攻击者，叫单向 ARP 欺骗。
双向欺骗才能实现完整中间人。

攻击效果：
1.抓受害者 HTTP 明文账号密码；
2.配合 SSLStrip，把 HTTPS 降级 HTTP 窃取信息；
3.篡改 HTTP 网页内容，注入恶意 JS 木马；
4.拒绝服务 DoS：不转发流量，受害者直接断网。

中间人攻击 MITM：

原理：
攻击者秘密插入通信双方中间，转发、窃听、篡改双方数据，通信的 A 和 B 以为直接对话，完全不知道第三方存在。
例如：你写信给朋友，信先落到坏人手里。坏人拆开看内容，可以原封不动转发，也可以改掉信里内容再寄过去，你们两边都以为信件直接互相传递。

完整流程：
1.A 想和 B 建立通信；
2.攻击者 C 劫持链路，A 实际和 C 对话，C 伪装成 A 跟 B 对话；
3.C 收到 A 的消息：可以窃听 / 修改 / 丢弃，再发给 B；
4.B 回复消息，同样经过 C 处理，再回传给 A；
5.A、B 都认为彼此在直接通信，不知道 C 存在。
核心条件：攻击者要能访问两者之间的网络链路。

危害：
1.窃听：拿到账号、cookie、聊天内容；
2.篡改：转账请求修改收款账户、篡改下载文件植入木马；
3.替换证书：伪造证书，解密 HTTPS 流量（证书欺骗）；
4.会话劫持：窃取会话 Cookie，直接登录你的账号。
但是：
MITM ≠ 窃听
MITM 不止听，还能改数据；单纯抓包只是窃听。
HTTPS 不是万能的：一旦你信任攻击者的伪造根证书，HTTPS 完全失效。

如何防御生日攻击

生日攻击的核心：利用哈希碰撞，构造两份不同消息，哈希值相同。它攻击的是哈希函数的抗碰撞能力，不是解密密钥。

1.使用抗碰撞安全的哈希算法

生日攻击代价约 2的n/2次幂，n 是哈希输出比特长度。

  • SHA‑256：输出 256 位，生日攻击需要2的128次幂
  • SHA‑3：海绵结构，抗碰撞性能更强
    只增大密钥长度没用，必须增大哈希输出长度。

2.区分两种安全属性
1.抗原像：给定哈希 h，很难找到消息 M 使 hash (M)=h（找对应原文），复杂度2的n次幂
2.抗第二原像：给定消息M1，找另一个M2!=M1，满足(hash(M1)=hash(M2))
3.抗碰撞：找任意一对 (M1≠M2)，哈希相等，生日攻击就是针对这个，复杂度2的n/2次幂)

3.协议层面防护

①加随机数

不要直接 hash(消息)，改为 hash(消息 || 随机数)

  • 每次签名 / 校验，附加一个不可预测的随机 nonce。
  • 攻击者预先算好的碰撞文档直接作废，因为每一次附带不一样随机值，预计算的碰撞失效。
    随机数不能固定写死，必须每次全新生成密码学随机数。

② 加入时间戳

hash(消息 || nonce || timestamp)
防止攻击者拿很久以前构造好的碰撞文档重放攻击。

简单鸽巢原理：

把 (n+1) 个物体，放进 n 个盒子。
至少有一个盒子包含 ≥2 个物体。

例子：

1.13 个人，至少两个人生日月份相同。
鸽子 = 13 个人；抽屉 = 12 个月份。(13>12)，必然至少两人同月出生。
2.3 双不同袜子，随手拿 4 只，至少两只袜子是同一双。

广义鸽巢原理

把 (k*(n+1)) 个物体放进 n 个盒子
至少一个盒子里面有不少于 (k+1) 个物体。
例子：25 个苹果放到 4 个篮子
25=4*6+1，k=6,n=4
所以至少一个篮子，有 (6+1=7) 个苹果。

公式表达：
将 m 个对象分到 n 个容器，至少一个容器的数量：
[m/n],[x]表示向上取整。

DNS劫持：
四种主要攻击方式：
1.终端本地劫持
修改操作系统 DNS 服务器地址，全部解析请求发送到攻击者 DNS 服务器；
修改hosts文件，hosts 优先级高于 DNS，直接写死域名指向恶意 IP，不走网络 DNS 查询。

2.路由器 DNS 劫持

攻击者利用路由器弱口令、路由器漏洞登录管理后台，修改路由器 WAN 口 DNS，填入恶意 DNS 服务器地址。
连接这个 Wi‑Fi 的所有手机、电脑全部中招。

3.中间人劫持

公共免费 WiFi 环境，攻击者做 ARP 欺骗，拦截内网 DNS 请求；不等合法 DNS 返回，抢先回复伪造 IP 报文。
不需要修改任何设备配置，只要连这个 WiFi 就中招。

4.服务器端劫持
入侵运营商递归 DNS 服务器、域名权威服务器，直接修改解析记录，会影响成千上万用户，攻击门槛很高。

典型受害现象：
1.浏览器地址栏域名完全正确，页面却是广告、赌博、钓鱼网站。
2.访问 HTTPS 网站弹出证书错误警告（假冒网站拿不到合法证书）。
3.QQ、微信可以登录，网页打不开；聊天软件内置 IP 库，不走 DNS 解析。
4.网页自动弹窗、强制跳转。

风险危害：

1.钓鱼网站窃取账号密码。
2.诱导下载木马病毒。
3.注入广告，篡改网页内容。
4.企业内网环境下，劫持业务域名造成内网系统被冒充。

APT 属于高等级网络攻击
APT 完整攻击链路（深度流程）
侦察阶段：
攻击者大量搜集目标公开信息：员工邮箱、社交账号、官网文档、业务系统版本，摸清内部细节，定制攻击方案。
常用手段：
鱼叉钓鱼邮件
利用 0day 漏洞
供应链攻击
立足潜伏
入侵一台主机后，不会立刻乱搞。
在机器上留后门，清除系统日志，掩盖入侵痕迹，修改权限，伪装成正常系统进程，杀毒软件很难发现。
APT核心特征：横向移动
拿下一台电脑只是起点。
在内网里扫描其他主机，窃取账号密码，利用域权限，一台一台往服务器、数据库渗透，不断扩大控制范围，在内网到处 “游走”。
数据收集与外渗：
偷偷拷贝图纸、数据库、机密文档，把加密后的数据，通过伪装成正常网络流量，偷偷传到攻击者服务器。全程尽量不触发告警。
行动：
时机到了，要么窃取大量数据带走；也可以搞破坏（删数据、破坏工业控制系统）；最后清理痕迹，销毁入侵日志，悄悄撤离。
防御思路：
内网分段隔离
监控日志
限制高权限账号
警惕鱼叉钓鱼
定期威胁狩猎

BOM：操控浏览器窗口本身（地址栏、弹窗、刷新、前进后退、定时器）
DOM：操控网页页面内容（文字、图片、按钮、样式、标签结构）
二者顶层都是 window 对象，浏览器打开页面就自动生成 window，所有属性都挂载在它身上。 DOM 树结构：
window
└── document（文档根节点）
├── html
├── head
└── body
├── div
├── p
├── button

页面每一个标签、文字、注释，都是一个节点 node。
BOM含五大核心对象：
window、location、history、navigator、screen
类别 操控对象 核心作用 典型内容
DOM 网页 HTML 文档 修改页面内容、样式、结构 获取标签、改文字、绑定点击事件、创建列表
BOM 浏览器窗口 操控浏览器软件本身 定时器、跳转网址、刷新、前进后退、窗口滚动、本地存储

学习笔记8

木马全称特洛伊木马，名字源自古希腊特洛伊战争的木马计。
它本身不会自我复制传播（这点和普通电脑病毒不一样），外表伪装成正常文件，一旦你主动点开、安装运行，就会悄悄潜入电脑设备，偷偷窃取信息、操控设备。
木马和普通病毒的区别：

普通病毒：主打自我复制、破坏文件、拖慢系统，会到处传染；
木马：没有大肆传染能力，目的大多是偷资料、远程控制、盗取账号钱财，隐蔽潜伏。
木马常见伪装样式：
日常最容易碰到的几类：
文档、压缩包
社交软件中发来：简历、成绩单、照片压缩包、财务表格等
工具类文件：
壁纸、字体、资源素材、绿色版软件。
捆绑木马原理：
黑客把正常软件 / 图片 / 文档和木马病毒程序打包合并成一个文件，你双击打开看似运行了正常内容，暗地里木马同步悄悄启动，这就叫文件捆绑。
好比一个礼盒：
外层包装印着好看的图案（你想要的游戏、壁纸、补丁）；
礼盒里面分两层：上层是你想要的东西，底层偷偷藏了小偷（木马）；
你拆开礼盒翻看礼物时，底下的小偷趁机溜进你家里（电脑后台）躲起来。

零知识证明：
通俗来讲，零知识证明就是我让你相信我说的一句话或一个结论而不需要向你透露任何有关该结论的有用信息。
零知识证明有三大核心特性：
第一，完备性（Completeness）：
真的陈述，诚实执行必被接受（∀x∈L, Pr[接受]=1）。
第二，可靠性（Soundness）：
假的陈述，作弊成功概率 ≤ negl(λ)，可忽略；更强地，若能骗过，则必存在抽取器 E 提取出 w——即知识可靠性（PoK）。
第三，零知识（Zero-Knowledge）：
验证者除”命题为真”外一无所获；严格地，存在模拟器 S 造出与真实交互不可区分的记录。
举个简单的例子：
Alice 手里藏着一个秘密数字：密码 = 73
Bob 要确认：Alice 确实知道这个数字，但绝对不能让 Bob 得知数字是多少。
1.交互式零知识证明：
规则前置：
我们规定一道运算：
数字 x 经过固定公式计算后，结果永远等于 200
公式：x + 127 = 200
只有 x=73 能满足式子。
交互步骤
Alice 提前算出结果，私下准备好，不告诉 Bob 数字；
Bob 随机出题考验 Alice，两种指令随机选其一：
指令 A：你告诉我运算最终结果
指令 B：你把你的数字带入公式演算一遍
一轮过程：
假如 Bob 喊指令 A：Alice 回复最终得数 200
假如 Bob 喊指令 B：Alice 完整演算，结果依旧是 200
为什么骗不了人？
如果 Alice 根本不知道数字，只能瞎蒙：
每一轮猜对概率只有 1/2
连续 20 轮全部答对，蒙混过关概率：≈百万分之一，基本可以认定没有作假。
最终效果
Bob 全程不知道数字是 73，但是百分百确定：Alice 拥有正确数字。

学习笔记6

JS 全称：JavaScriot，简称 JS
JS 负责交互逻辑（切换文字，轮播图，表单验证，弹窗，数据请求等）
JS特点：
弱类型语言：不用提前规定变量类型
解释型：浏览器直接运行，不需要编译
既能跑浏览器，也能跑服务器
声明变量三种方式
1 var：
var name = “张三”;

2 let：
let age = 18;
age = 数值;

3 const：
const PI = 3.1415;（常量）
命名规则：
不能以数字开头
不能是 JS 关键字：let、const、if、for、function 等
区分大小写
