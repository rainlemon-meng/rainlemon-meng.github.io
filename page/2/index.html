简单的XSS寻找flag



题目要求击杀 1000 只丧尸拿 flag，手动打几乎不可能。
这是前端网页游戏，分数逻辑写在前端 JS 代码里，属于前端篡改 / XSS 相关思路，不需要真的射击。
寻找flag的方法：
1.先打开控制台，再访问游戏页面（最有效）
2.新建一个空白浏览器标签
3.按下 Ctrl+Shift+I 先把开发者工具调出来
4.在这个标签地址栏粘贴游戏链接访问

页面里有一个文件 challenge.js，可以打开搜索 flag，部分题目 flag 直接写在这个文件内。

含义：你可以在开发者工具控制台调用函数 getFlag(1000)

右侧开发者工具切换到 控制台（Console）
直接输入下面代码，回车执行：
javascript
运行
getFlag(1000)
执行之后页面就会弹出 Flag。

Hexo写新文章+发布步骤

一、新建博客文章
打开 CMD，定位在 D:\myblog
执行这条命令创建文章：
bash
运行
hexo new “文章标题”
文件位置
生成的文章在这里：
D:\myblog\source_posts\你的文章标题.md
用记事本 / VS Code 打开这个 .md 文件。
书写规则
文件顶部是文章配置（不要删除）
markdown
title: 我的第二篇博客
date: 2026-07-29 18:00:00
tags: [学习,Hexo]
categories: 随笔

这里下面写正文内容，使用Markdown语法
可以写文字、插入图片、列表等
— 上面是配置，下面才是网页展示的正文。写完保存文件。
二、本地预览（推荐！先看效果再发布）
CMD 执行：
bash
运行
hexo g && hexo s
浏览器打开 http://localhost:4000
查看你的博客，确认排版、图片没有问题。
三、生成静态网页 + 推送到 GitHub 上线（核心发布流程）
以防hexo d 会卡住，使用这套稳定命令
bash
运行
hexo clean && hexo g
cd public
git add .
git commit -m “新增文章：xxx”
git push -f origin gh-pages

终端最后一行：

  • [new branch] gh-pages -> gh-pages
    代表网页文件已经全部上传到 GitHub 仓库的 gh-pages 分支。
    步骤拆解
    hexo clean && hexo g：清理旧网页，重新生成全部网站文件
    cd public：进入网页文件夹
    git add .：记录所有改动
    git commit -m “描述”：填写更新备注，随便写
    git push -f origin gh-pages：强制推送到 GitHub 博客分支
    1.点击页面上方 Settings
    2.在左侧找到 Pages
    3.配置：
    Source：Deploy from a branch
    Branch：选择 gh-pages
    Folder：/(root)
    点击保存(save)。

    四、等待网站更新
    推送命令跑完没有报错，等待 3～10 分钟
    无痕浏览器打开：你所建立的博客网址， 查看新文章。
    常用小提示
    如果想删除文章：
    直接删除 source_posts 对应的 .md 文件，再完整执行一遍发布命令；
    tag 标签、分类写错，直接修改 md 文件内顶部内容；
    不要手动修改 public 文件夹内文件！
    public 是自动生成的，所有修改只能在 source_posts 里操作。
    五、更新博客固定流程（保存备用）
    CMD 执行：
    bash
    运行
    hexo clean && hexo g
    cd public
    git add .
    git commit -m “更新文章”
    git push -f origin gh-pages
    推送完成后等待几分钟，网站自动更新。

搭建属于自己的博客

一、前期环境准备

  1. 安装必备软件
    Git
    下载：https://git-scm.com/
    安装后打开终端验证：
    bash
    运行
    git –version
    Node.js（Hexo 依赖）
    官网下载 LTS 长期支持版：https://nodejs.org/

    搭建 Hexo 静态博客场景）
    保持全部默认勾选，直接点 Next 下一步！
    验证安装：
    bash
    运行
    node -v
    npm -v
    只要出现版本号，就代表 Node 安装没问题。
  2. 注册账号
    GitHub 账号：https://github.com
    重点仓库命名规则：用户名.github.io（必须严格小写，用来开启 GitHub Pages）
    二、Hexo 本地初始化博客（本地写作环境）
  3. 全局安装 Hexo
    打开 cmd

    plaintext
    added 54 packages in 1m
    只要出现这一行，代表安装完成。
    关于下面一堆 warn、notice
    黄色 warn 警告
    只是脚本权限提示，不影响 Hexo 正常使用，可以直接忽略。
    bash
    运行
    npm install -g hexo-cli
  4. 创建博客文件夹并初始化
    bash
    运行

创建文件夹

hexo init myblog

进入目录

cd myblog

安装依赖

npm install
此时目录结构简单说明：
plaintext
myblog/
├── _config.yml # 【最重要】全局配置文件
├── source/ # 源文件目录
│ └── _posts/ # 所有markdown文章放在这里
├── themes/ # 博客主题文件夹
├── public/ # hexo generate 生成静态文件（部署就是上传这个文件夹）
3. 本地启动预览
bash
运行
hexo s

全称 hexo server


按ctrl+c表示停止。
浏览器访问：http://localhost:4000
此时你已经拥有本地可以访问的博客！
