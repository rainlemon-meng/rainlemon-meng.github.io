学习笔记4

一、基础网页骨架：
DOCTYPE html
声明文档类型
html lang=”zh‑CN”
html：lang=”zh‑CN” 代表网页语言是中文 

<head：网页头部，存放页面配置，内容不会显示在页面上 
<meta charset="UTF‑8">
<!-- meta字符集：设置编码，防止中文乱码，必须写 -->
<title>我的第一个网页</title>
<!-- title：浏览器标签页上面显示的标题 -->

head
body
body：网页主体，所有看得见的内容全部写在这里！！
这里写页面内容

二、常用标签分类：
标题标签 h1 ~ h6
h1 最大，h6 最小，有语义，代表标题
三、网页里面要用字符，不能直接打空格：
空格： nbsp;
小于： lt;
大于： gt;

各类元素：

1、块级元素 block
特点：独占一行，可以设置宽高
代表：div h1~h6 p ul ol li header main footer

2、行内元素 inline
特点：一行多个并排，不能设置宽高，大小跟随内容
代表：span a b em strong

3、行内块 inline‑block
特点：一行多个并排，可以设置宽高
代表：img input textarea

❌HTML 常见坑
忘记写 </>闭合标签，页面布局乱掉。
img 的 src 路径写错，图片不显示。
表单 input 不写 name，提交拿不到数据。
单选框 radio 的 name 不相同，结果可以同时多选。
中文页面忘记写出现乱码。
