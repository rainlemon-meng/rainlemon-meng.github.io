“学习笔记15”

ARP 欺骗：

ARP 欺骗是局域网内实现中间人 MITM 攻击最经典的手段。

ARP：地址解析协议
作用：把IP 地址 → MAC 物理地址。
ARP 协议设计的缺陷：ARP 应答报文不需要收到请求也可以主动发送。
主机收到 ARP 回复，就直接更新自己 ARP 缓存，不会严格验证真假。攻击者就利用这个漏洞。

ARP 欺骗攻击流程（MITM 模式）

环境：

A：受害者电脑
R：路由器网关
C：攻击者主机

1.攻击者 C 持续发送伪造 ARP 应答包
A 的 ARP 缓存被篡改：网关 IP 对应的 MAC 变成攻击者机器。
于是受害者 A 所有上网流量，全部发给攻击者 C，而不是真实路由器。
发给受害者 A：网关 IP → 攻击者 C 的 MAC
2.攻击者同时发给网关 R 发送伪造 ARP 应答
网关回给 A 的流量，也先发给攻击者 C。
发给网关 R：受害者 A 的 IP → 攻击者 C 的 MAC
3.攻击者开启流量转发
攻击者机器收到双向流量，可以：
单纯窃听抓包
修改数据包内容
丢弃数据包制造断网
再把流量转发给真实网关 / 受害者
结果：A 对外所有网络流量全部经过攻击者 C，完成局域网中间人 MITM。
如果攻击者只欺骗受害者，不欺骗网关：受害者能上网，但是所有外网流量先过攻击者，叫单向 ARP 欺骗。
双向欺骗才能实现完整中间人。

攻击效果：
1.抓受害者 HTTP 明文账号密码；
2.配合 SSLStrip，把 HTTPS 降级 HTTP 窃取信息；
3.篡改 HTTP 网页内容，注入恶意 JS 木马；
4.拒绝服务 DoS：不转发流量，受害者直接断网。
