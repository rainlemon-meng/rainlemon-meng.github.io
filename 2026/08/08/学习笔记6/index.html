学习笔记6

JS 全称：JavaScriot，简称 JS
JS 负责交互逻辑（切换文字，轮播图，表单验证，弹窗，数据请求等）
JS特点：
弱类型语言：不用提前规定变量类型
解释型：浏览器直接运行，不需要编译
既能跑浏览器，也能跑服务器
声明变量三种方式
1 var：
var name = “张三”;

2 let：
let age = 18;
age = 数值;

3 const：
const PI = 3.1415;（常量）
命名规则：
不能以数字开头
不能是 JS 关键字：let、const、if、for、function 等
区分大小写
