学习笔记5

CSS：负责网页样式与外观
文件后缀：.css，可以写在 HTML 标签内、页面头部、独立 css 文件
内部样式表
写在 html 的 style 标签中，放在head里面，当前整个页面生效
html
head
style
div {
color: blue;
}
style
head
CSS 语法格式：
选择器 {
属性名: 属性值;
属性名: 属性值;
}
选择器：选中要改样式的 HTML 标签
属性：要修改的样式（颜色、大小）
属性值：样式的具体设置
每一条以 ;结尾
CSS 单位：
px：像素，固定大小，最常用
%：百分比，相对于父盒子大小
rem：相对于 html 根标签字体大小，移动端适配用
em：相对于自身字体大小
多个选择器选中同一个标签，看权重大小，大的覆盖小的
通配符*：0
标签选择器：1
class 类选择器：10
id 选择器：100
行内 style：1000
